
# 🎓 StudyNotion – MERN EdTech Platform



🚀 StudyNotion is a full-stack EdTech platform built using the MERN (MongoDB, Express.js, React, Node.js) stack.
It enables students to enroll in courses, instructors to create & manage courses, and provides admins with category management.
The platform includes interactive features, secure payments, and a modern UI for seamless online learning.

Live Website: https://studynotion-deploy.onrender.com/


#  ✨ Features

## 👑 Admin

🔐 Authentication: Admin login with secure credentials.

📂 Category Management: Create & manage course categories.


## 👨‍🏫 Instructors

🔐 Authentication: Secure instructor login.

📝 Course Creation: Create and manage courses with details & pricing.

🎥 Lecture Uploads: Upload and manage lectures.

💳 Payment Integration: Collect payments with Razorpay.

📊 Enrollment Tracking: Track enrolled students.

💰 Revenue Insights: Monitor revenue for each course.

📈 Interactive Charts: Visualize course data with Chart.js.

## 👩‍🎓 Students

🔐 Authentication: Secure student login.

🛒 Course Enrollment: Purchase and enroll in courses.

⭐ Review System: Leave reviews using React-Stars.

🎡 Review Display: Slider-based reviews with Swipe Slider.

💻 Interactive UI: Easy-to-use learning interface.
## 🔧 Technologies Used

* Frontend: ⚛️ React, JavaScript

* Backend: 🟢 Node.js, Express.js

* Database: 🍃 MongoDB

* Payments: 💳 Razorpay

* Media Storage: ☁️ Cloudinary

* Data Visualization: 📊 Chart.js

* UI Components: ⭐ React-Stars, 🎡 Swipe Slider
